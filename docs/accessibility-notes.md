# הערות נגישות — שלב 2

מומשו lang=he ו-dir=rtl, landmarks, היררכיית כותרות, תפריט עם aria-label, קישור דילוג, מיקוד נראה ותמיכה ב-prefers-reduced-motion. דמויות עם טקסט חלופי; הכותרות המודפסות בכרטיס דקורטיביות לקורא מסך ומקבלות תוויות dt נגישות עבור ערכי HTML אמיתיים.

חלונית ההדגמה משתמשת ב-dialog.showModal, שם נגיש, כפתור סגירה וחזרה למפעיל בעת סגירה. ניהול המיקוד ו-Escape מסתמכים על התנהגות dialog מקורית; טרם אומתו בדפדפן בסביבה זו. אין טענה לעמידה מלאה ב-WCAG 2.1 בשלב זה.

פעילויות הלמידה מוצגות כשלד סטטי ולא ככפתורים חסרי פעולה. כפתור בדיקת הבוחן מושבת ומלווה בהסבר גלוי. חלופות מקלדת לגרירה, משובים חיים, אימות קלט ואינטראקציות שם המשפחה יתווספו רק בשלב המאושר הבא.

נדרשת בדיקה ידנית: רצף Tab, נראות focus, חלונית עם Escape וחזרה למפעיל, זום 200%, קורא מסך בעברית, ניגודיות מול טקסטורות, גודל יעדי ניווט, ואי-חפיפה עם הכותרת הדביקה. רכיבים גנריים קטנים במובייל טעונים בדיקת מגע אמיתית; אין לטעון שכבר נבדקו.
