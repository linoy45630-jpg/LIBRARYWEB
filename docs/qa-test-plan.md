# תוכנית בדיקות — שלב 2

עדכון 10 בנובמבר לפי אפיון 9 בנובמבר: עברו 56 בדיקות Node עם DOM מדומה; בדיקות דפדפן עכבר/מקלדת/מובייל לא בוצעו עקב אי-זמינות browser access host. יש לבדוק מעבר שלבים, אי-עקיפה, עיון חוזר, ספר קיים ובוחן חלקי מול תצוגת הפיתוח. [הדוח העדכני](revised-spec-implementation.md) גובר על תיאורי שלבים היסטוריים בהמשך.


עדכון סוד 3: עברו 14 בדיקות אירועים וסדר עברי, ועוד 23 בדיקות רגרסיה לסודות 1–2, עם DOM מדומה. [תוצאות ומגבלות](secret-3-implementation.md). הסוד השלישי פעיל; הבוחן לא שונה. בדיקות דפדפן מקלדת/מגע/פריסת 1440/1024/768/390 עדיין דורשות ביצוע ידני; אין לראות בבדיקות האירועים אישור רספונסיביות או WCAG.

עדכון סוד 2: 12 בדיקות לוגיקה ואירועים לסוד 2 ו-11 בדיקות רגרסיה לסוד 1 עברו ב-Node עם DOM מדומה. [תוצאות ומגבלות](secret-2-implementation.md). בדיקות דפדפן עכבר/מקלדת ופריסות 1440/1024/768/390 לא בוצעו בסבב זה, עקב אי-זמינות browser access host. אישור סוד 1 הידני הוא דיווח המשתמשת, לא בדיקה שבוצעה על ידי הסוכן.

עדכון שלב 3א: [מימוש ובדיקות סוד 1](secret-1-implementation.md). עברו 11 בדיקות אירועים ב-Node עם DOM מדומה. פעילות סוד 1 כבר אינה תצוגה סטטית; יתר המקטעים נשארו ללא שינוי. בדיקות דפדפן עכבר/מקלדת/מובייל חסומות כרגע עקב עצירת כלי Computer Use בזיהוי URL. אין להסיק מהתוכנית ההיסטורית שלהלן שאינטראקציות אלה נבדקו בדפדפן.

## בוצע

- בדיקת תחביר ארבעת קובצי JavaScript באמצעות parser של Node, לאחר הסרת משפטי import/export לצורך בדיקת התחביר של הגוף. קובץ נתוני התוכן נטען גם כמודול.
- כל מחרוזות התוכן בקובץ approved נמצאו באפיון שחולץ.
- בשאלה 1 יש בדיוק שלוש מחרוזות מקור; בתצוגה הן מוצגות בסדר 3, 1, 2.
- משאבי HTML/CSS/JavaScript והתמונות הישירות שנבדקו החזירו HTTP 200.
- אין הפניה ל-background-experiments בקובצי האתר. הרקע מוגדר במשתנה יחיד ומסומן כזמני.
- חיתוכי הדמויות והכפתורים נבדקו כקובצי תמונה. חיתוך תולי תוקן כך שיכלול גם את ראשו ואת הקישוטים המקוריים במלואם וללא דמות שכנה.

התוצאות הטכניות ב-qa/phase-2-static-checks.json. בדיקות אינן מכסות הפעלת DOM בדפדפן.
