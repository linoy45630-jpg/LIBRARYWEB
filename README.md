# מוצאים ספר בספרייה — בין השורות

שלב 2: תשתית חזותית מקומית לבדיקה. יחידת הלמידה עדיין אינה פעילה במלואה. אין חיבור SCORM/LMS ואין פרסום לאתר חיצוני.

## תצוגה מקומית

התצוגה הפעילה במהלך העבודה: http://127.0.0.1:4173

לפתיחה חוזרת ב-VS Code: לפתוח את `index.html` באמצעות **Open with Live Server**. אין צורך בהתקנת תלויות או בתהליך build. יש להשתמש בשרת HTTP מקומי, משום שקובצי JavaScript נטענים כמודולים ולא דרך file://. שרת התצוגה הפעיל תלוי בהמשך פעילות סביבת הכלים; Live Server הוא דרך ההפעלה החוזרת המומלצת בסביבת הפרויקט.

## מה נכלל

- HTML סמנטי בעברית וב-RTL, ניווט עוגנים וקישור דילוג.
- פתיחה, storyboard זמני, שלושה מקטעי סודות, מבנה בוחן, אזור סיום ו-footer.
- Bootstrap RTL 5.3.3 מקומי, ללא JavaScript של Bootstrap שנחוץ בשלב זה.
- רכיבים חוזרים לכרטיס ספר עם ערכי HTML, דיאלוג, ספרי פעילות ושלטי מדפים.
- דמויות ובועת דיבור שנחתכו מהמקורות בלבד. שלושת מצבי כפתור הטורקיז.
- חלונית רכיב לדוגמה ב-footer; מסגרת טורקיז להדרכה ותמיכה במחלקת secondary למסגרת בורדו.
- ניווט רגיל וחלונית הדגמה בלבד. אין פתיחת ארבעת ספרי הלימוד, בחירת ז׳אנר, חיפוש אלפביתי, גרירה או בדיקת תשובות.

## החלפת הרקע הזמני

ב-`css/styles.css`, לשנות רק את הערך של `--library-background` לנתיב הרקע הסופי. מיקום הרקע וקנה המידה מטופלים בנפרד. לאחר החלפה יש לבדוק את החיבור ואת גודל הפרטים בארבעה רוחבי מסך.

נכס 9 המקורי הוא **רקע זמני עם חיבורים גלויים**. הוא נגלל עם העמוד וחוזר אנכית. אין שימוש בקומפוזיציות הניסוי ואין טענה שהרקע הזמני seamless. אין עבודה נוספת על חיבור המדרגות במסגרת שלב זה.

## מבנה הקוד

- `js/content.js`: תוכן שנלקח כלשונו מהאפיון המאושר מ-8 בנובמבר.
- `js/provisional-content.js`: פרטי ספר ומחברים בדיוניים, שאלות עתידיות ריקות והגדרת מדיה שעדיין אינה זמינה.
- `js/components.js`: יצירת כרטיס ספר ודיאלוג. כותרות הכרטיס מודפסות בתמונה; תוויות מקבילות לקורא מסך בלבד.
- `js/main.js`: הרכבת התצוגה, חלונית הדגמה ומצב מיקום בתפריט. אינו מנהל התקדמות לימודית.
- `assets/derived/components/crops.json`: מיקום כל חיתוך במקור. המקורות נשמרו.
- `docs/qa/phase-2-static-checks.json`: תוצאות בדיקות סטטיות וטעינת משאבים.

## פתוח לבדיקה ולאישור

הרקע המחזורי הסופי, בריף הספרייה שעדיין לא נמצא ב-docs, הווידאו/כתוביות/קריינות, נוסחי קישור חסרים, יתר שאלות הבוחן ונוסח הסיום. שאלה 1 מציגה בדיוק שלושה שלבים מאושרים בסדר מעורבב. אין שאלות חדשות מומצאות.

תצוגת הסוד הראשון אינה מציגה את כרטיס הספר; חשיפתו בעת פתיחת ספר 3 תתבצע בעת מימוש האינטראקציות. חלונית כרטיס הספר הנגישה מה-footer היא הדגמת רכיב נפרדת לבדיקה בלבד.

## מגבלות אימות

בדיקות תחביר JavaScript, התאמת מחרוזות התוכן שבנתונים לאפיון, שלושת כרטיסי שאלה 1, קישורי עוגנים וטעינת משאבים ב-HTTP בוצעו. החיתוכים נבדקו חזותית כקובצי תמונה. אין עדיין אישור QA של עמוד מרונדר: הדפדפן המשולב לא היה זמין, ו-Computer Use המקומי נעצר משום שלא זיהה את כתובת הדפדפן בוודאות. לכן בדיקות מסך ב-1440, 1024, 768 ו-390, מיקוד מקלדת, קורא מסך, גלישה אופקית וקונסולה נותרו לבדיקה ידנית. אין להציג את תוכנית הבדיקה כתוצאות שעברו.

העבודה נעצרת לאחר שלב 2; אין להמשיך לאינטראקציות המלאות לפני אישור המשתמשת.
